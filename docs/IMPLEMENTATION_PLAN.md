# Phase 1 实现计划

1. 先用纯 TypeScript 完成七时段时钟、属性约束、条件解析、种子随机数和版本化存档。
2. 将事件 JSON 通过 EventEngine 过滤：角色、地点、时段、日期、标记和单次触发状态；无匹配时使用默认行动。
3. 用 Phaser 绘制可替换的校园占位背景，用 HTML 交互层承载手机友好的 HUD、事件对话和日志。
4. 编写班长线前三天事件：每天至少两个有状态后果的事件，第三天用前两天标记决定可用分支。
5. 用 Vitest 验证核心系统，用 Playwright 验证启动、选择、保存恢复和竖屏布局。

后续阶段应在保留这些接口的前提下增加眼保健操事件池、五名初始角色的内容、解锁树和特殊角色系统。
