# Phase 1 假设与取舍

- 设计文档没有给出班长前三天的具体事件 JSON，因此本阶段新增了“粉笔头、赊账本、办公室钥匙、天台集合、第三天广播”五组校园事件；事件只服务 Phase 1，不替代未来完整剧情。
- 七个时段都允许一次选择；无事件时使用默认休息/观察行动，保证时间轴不会卡住。
- 放学后优先在天台、教室和走廊寻找事件，午休优先在小卖部和走廊寻找事件；这些是 Phase 1 的地点选择默认值。
- 风险结果采用互斥的成功、失败、被抓三分支；怀疑值达到 80 时仅将被抓概率翻倍并统一限制在 0–100%。具体平衡系数集中在事件 JSON 的风险字段。
- 当前 Phaser 只负责背景占位渲染，HTML 交互层负责文字、按钮和可访问的状态展示。
- 文档中“班长线”既可以指玩家扮演班长，也可以指与班长有关的关系线。本阶段采用玩家扮演班长的视角，重大关系冲突留到后续设计评审。
